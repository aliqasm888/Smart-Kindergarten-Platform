# Smart Kindergarten Platform

A backend-driven kindergarten management and child support platform that combines academic organization with AI-based behavioral analysis.  
The system is designed for kindergarten students, parents, teachers, and administrators, and includes educational games, role-based access, speech-to-text support, and a knowledge-based chatbot for preliminary autism-related screening.

---

## Project Overview

This project is a complete platform for kindergarten environments. It supports daily academic management while also integrating intelligent tools to help monitor children's attention, focus, and distraction levels through interactive games.

The system organizes children by kindergarten levels (**KG1, KG2, KG3**) and provides access to class information, schedules, lessons, exam plans, weekly timetables, and homework. In addition, it includes game-based analysis features that use children's performance in interactive activities to estimate indicators related to concentration and attention.

The platform also includes:
- **Speech-to-text functionality** for selected games and activities
- A **knowledge-based system (KBS)** in the form of a chatbot for parents
- A **multi-role authentication system** for administrators, teachers, parents, and children

The KBS component asks parents a set of structured questions and provides a confidence-based preliminary result regarding autism-related indicators. This is intended as an assistive screening tool only and not as a medical diagnosis system.

## Core Features

### 1. Kindergarten Academic Management
The system provides academic and organizational features for kindergarten students, including:
- Kindergarten level assignment (**KG1, KG2, KG3**)
- Class and section information
- Lesson schedules
- Weekly timetables
- Number of study hours
- Exam schedules
- Homework and tasks

### 2. Educational Games
The platform includes interactive games designed for kindergarten children.  
These games are not only educational, but also used as a source of behavioral data for analyzing:
- Attention
- Focus
- Distraction

### 3. AI-Based Behavioral Analysis
The project uses children's game performance as an input for behavioral analysis.  
Based on the available data, the system helps estimate indicators related to:
- Concentration level
- Attention level
- Distraction level

This analysis is intended to support educational monitoring and early observation.

### 4. Speech-to-Text Integration
Some games and activities include speech-based interaction.  
For this purpose, the platform supports **speech-to-text** functionality, allowing spoken input to be processed as text within selected learning activities.

### 5. Knowledge-Based System (KBS)
The project includes a chatbot-based **knowledge-based system** for parents.  
This module:
- asks structured questions
- uses rule-based logic or predefined knowledge patterns
- provides a confidence-based preliminary output regarding autism-related indicators

This component is designed as an assistive tool and should not be considered a replacement for clinical or professional diagnosis.

### 6. Role-Based Access Control
The platform supports authentication and access control for different user roles:
- **Administrator**
- **Teacher**
- **Parent**
- **Child**

Each role has access to the features relevant to its responsibilities.

## User Roles

### Administrator
- Manages the overall system
- Controls users and roles
- Organizes academic data and structure

### Teacher
- Follows student progress
- Manages lessons, homework, and exam-related content
- Reviews educational and behavioral information

### Parent
- Monitors the child’s academic information
- Accesses schedules, homework, and exam plans
- Uses the KBS chatbot for preliminary screening support

### Child
- Interacts with educational games and activities
- Accesses content relevant to their level

## Scientific and Practical Basis

This project is based on the idea that structured observation of child interaction, especially through age-appropriate educational activities, can support early educational monitoring. It also applies a **knowledge-based system** approach for guided parent interaction and uses **speech-to-text** as an assistive input method in selected tasks.

The platform does **not** claim to provide medical diagnosis. Any output related to behavioral conditions, including autism-related indicators, should be treated as preliminary and supportive only.

---

## Important Disclaimer

The autism-related screening functionality in this project is a **preliminary support tool** based on structured questions and confidence estimation.  
It is **not a diagnostic system** and must not be used as a substitute for professional medical or psychological evaluation.
