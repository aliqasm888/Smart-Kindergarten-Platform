# Smart-Kindergarten-Platform
Smart Kindergarten Platform: A complete system for managing kindergarten education with Laravel backend, Python AI for attention and focus analysis, interactive games, speech-to-text support, and a knowledge-based tool for parental guidance and early behavioral screening.
